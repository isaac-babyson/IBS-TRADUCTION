🔄 Conversation guidée

👥 À propos de IBS TRADUCTION

Parler pour se comprendre

Un prototype Web pour tester la reconnaissance vocale, la traduction et la lecture à voix haute dans les conversations bilingues.

Limites à connaître

Ce fichier n’est pas encore une application Android APK. Le service de traduction utilisé dans cette démonstration n’est pas une API garantie pour un usage commercial. Les langues de reconnaissance et de synthèse vocale varient selon l’appareil.

⬇️ Fichier et partage
